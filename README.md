# Churn_prediction

## Overview
This project uses Machine Learning to predict whether a customer is likely to leave a company (customer churn). By analyzing customer data, the model helps businesses identify customers at risk and improve customer retention.

## What This Project Does
- Loads and cleans the customer dataset.
- Performs data preprocessing and feature encoding.
- Explores the data using visualizations.
- Trains multiple Machine Learning models.
- Evaluates model performance.
- Selects the best model for churn prediction.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models
- Decision Tree
- Random Forest
- Gradient Boosting

## Project Goal
Build an accurate model to predict customer churn and help businesses make better customer retention decisions.

## Output
The project compares multiple classification models and identifies the best-performing model for customer churn prediction.
